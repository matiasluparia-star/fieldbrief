## Detailed description
FieldBrief is an independent prototype I built with AI-assisted development tools to show a practical service-business workflow. The responsive web interface captures a customer request, applies transparent triage rules, organises the job and produces an editable estimate. A real optional language model runs in a browser worker and generates an alternative assessment and reply. The core flow works without a paid API or account. All demonstration data is fictional. No client results or time savings are claimed.

The project includes modular JavaScript, input validation, quote calculations, JSON export, print styles, focused automated tests and clear setup documentation. I can scope a small adaptation around a specific intake form, document output or integration. Work is agreed against written acceptance criteria, with progress and handover documented in writing. Third-party services and usage costs are agreed separately.
